## 🤖 ARQUITETURA DE IA CONFIÁVEL

O Núcleo Tático utiliza uma pipeline de **7 camadas de validação** para garantir respostas precisas, seguras e sem alucinação:

```
Input → [1] Rebuff (Security Filter) → [2] Haystack + Sentence Transformers (RAG) 
      → [3] LLM (Kimi/Claude) → [4] Guardrails + Pydantic (Structure Validation)
      → [5] RAGAS (Hallucination Check) → [6] DeepEval (Quality Evaluation) 
      → [7] Response Output
```

| Camada | Ferramenta | Threshold |
|--------|-----------|-----------|
| Segurança | Rebuff | Block suspicious inputs |
| RAG | Haystack + Sentence Transformers | Top-5 retrieval |
| LLM | Kimi/Claude | Context-aware |
| Estrutura | Guardrails + Pydantic | Schema validation |
| Alucinação | RAGAS | Faithfulness ≥ 0.8 |
| Qualidade | DeepEval | G-Eval ≥ 0.7 |
| Output | — | Human-readable |

**Documento completo:** [ARQUITETURA_IA_CONFIAVEL_NUCLEO_TATICO.md](../ARQUITETURA_IA_CONFIAVEL_NUCLEO_TATICO.md)

## 🚀 COMO USAR

### Para Alunos
1. Navegue até o nicho desejado
2. Escolha o curso pelo código (NT-XXX-XXX)
3. Baixe o PACOTE_COMPLETO.zip
4. Estude na ordem: Curso → Slides → Prova

### Para Instrutores
1. Leia o POPS antes de ministrar
2. Siga o cronograma sugerido
3. Use os slides como roteiro
4. Aplique a prova ao final
5. Atualize-se pelos relatórios de inteligência tático-médica

### Para Desenvolvedores
1. Cursos seguem padrão Markdown (GitHub Flavored)
2. Templates disponíveis em `/templates`
3. Scripts de automação em `/scripts`
4. Siga o [CONTRIBUTING.md](./CONTRIBUTING.md)

## SEÇÃO 7: DEA (Slides 51-55)

**Slide 51 - FUNCIONAMENTO**
```
TÍTULO: Como o DEA funciona

[ETAPAS]
1. Analisa ritmo cardíaco
2. Detecta FV ou TV
3. Indica se choque necessário
4. Carrega capacitor
5. Aplica choque

[RITMOS]
✓ Desfibriláveis: FV, TV sem pulso
✗ Não desfibriláveis: Asistolia, AEP

[SEGURANÇA]
Não aplicará choque
se não necessário
```

**Slide 52 - OPERAÇÃO PASSO A PASSO**
```
TÍTULO: Usando o DEA

1️⃣ LIGAR
   Botão ON/verde
   Aguardar autoteste

2️⃣ ELETRODOS
   Adulto: DS + EI
```

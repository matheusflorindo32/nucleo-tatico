## SEÇÃO 6: DEA (Slides 41-45)

**Slide 41 - O QUE É DEA?**
```
TÍTULO: Desfibrilador

[DEFINIÇÃO]
Aparelho portátil que:
1. Analisa ritmo cardíaco
2. Detecta fibrilação
3. Aplica choque elétrico
4. "Reinicia" o coração

[SÍMBOLO UNIVERSAL]
💚 Coração verde + raio branco

[IMPORTANTE]
A cada minuto sem DEA:
-10% chance de vida
```

**Slide 42 - COMO USAR**
```
TÍTULO: Passo a passo

1️⃣ LIGAR
   Botão verde

2️⃣ SEGUIR VOZ
   Instruções automáticas

3️⃣ COLAR ELETRODOS
   Adulto: Dir. superior + Esq. inferior
   Criança: Peito + Costas

4️⃣ ANALISAR
   NÃO TOCAR na vítima

5️⃣ CHOQUE (se indicado)
   NÃO TOCAR na vítima

6️⃣ RETOMAR RCP
   Imediatamente após choque
```

**Slide 43 - DICAS IMPORTANTES**
```
TÍTULO: Cuidados com DEA

✅ Pode usar em criança
✅ Continue RCP entre choques
✅ Não tocar durante análise

❌ Não aplicar sobre água
❌ Não tocar durante choque
❌ Não substitui RCP

[LEMBRETE]
DEA + RCP = Melhor chance!
```

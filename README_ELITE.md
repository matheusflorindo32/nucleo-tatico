## 🛡️ Pipeline de Qualidade IA (7 Camadas)

```
Input do Usuário
       ↓
[1] 🔒 Security Filter (Rebuff)              → Bloqueia prompts maliciosos
       ↓
[2] 📚 RAG — Haystack + Sentence Transformers → Busca semântica em documentos
       ↓
[3] 🧠 LLM — Kimi K2.5                        → Geração de resposta
       ↓
[4] ✅ Structure Validation — Guardrails      → Valida formato e schema
       ↓
[5] 🔍 Hallucination Check — RAGAS            → Faithfulness ≥ 0.80
       ↓
[6] 📊 Quality Evaluation — DeepEval          → G-Eval ≥ 0.70
       ↓
[7] 📤 Response Output                         → Resposta confiável entregue
```

**Thresholds validados:**
- Faithfulness (RAGAS): **≥ 0.80**
- Answer Relevancy: **≥ 0.70**
- Contextual Precision: **≥ 0.75**
- Hallucination (DeepEval): **< 0.30**

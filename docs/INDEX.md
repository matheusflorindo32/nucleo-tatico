## 🏗️ Arquitetura

### Stack Tecnológica
- **Frontend:** Next.js 14 + Tailwind + shadcn/ui
- **Backend:** Supabase (PostgreSQL) + Edge Functions
- **Auth:** Supabase Auth (CPF + OAuth)
- **Pagamento:** Hotmart (PIX, boleto, cartão)
- **IA:** Kimi/Claude + RAG + CrewAI + MCP

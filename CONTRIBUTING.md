# 🤝 COMO CONTRIBUIR

Obrigado por querer contribuir com o Núcleo Tático! Este documento explica como você pode participar.

---

## 📋 REGRAS DE OURO

1. **Nunca copie sem licença** — Só incorporamos código MIT/Apache/BSD/ISC
2. **Evite GPL/AGPL/Fair-Code** — Risco jurídico alto
3. **Documente tudo** — Toda skill nova precisa de SKILL.md
4. **Teste antes de commitar** — RAGAS faithfulness ≥ 0.8
5. **Pense em português** — Nosso público é brasileiro

---

## 🎯 TIPOS DE CONTRIBUIÇÃO

### 1. Conteúdo Educacional
- Correções em apostilas e cursos
- Novos POPS (Procedimentos Operacionais)
- Questões de prova
- Referências bibliográficas ABNT

### 2. Código e Automação
- Novas skills para OpenClaw
- Scripts de automação (Python/Node.js)
- Integrações (APIs, webhooks)
- Dashboards e visualizações

### 3. Documentação
- Melhorias no README
- Guias de instalação
- Tutoriais de uso
- Traduções (espanhol, inglês técnico)

### 4. Inteligência Tático-Médica
- Monitoramento de guidelines internacionais
- Tradução de Change Proposals CoTCCC
- Análise de novos estudos (PubMed/arXiv)
- Alertas de novos editais de concurso

---

## 🔄 FLUXO DE TRABALHO

```
1. Fork → 2. Branch (feature/nome-descritivo) → 3. Commit → 4. Push → 5. Pull Request
```

### Padrão de commit:
```
[AREA] Descrição curta

- Detalhe 1
- Detalhe 2

Refs: #issue
```

**Áreas:** `[CURSO]`, `[IA]`, `[DOC]`, `[SKILL]`, `[FIX]`, `[FEAT]`, `[SEC]`

---

## 🧪 TESTES

Antes de submeter:
- [ ] Documentação atualizada
- [ ] Referências ABNT verificadas (NBR 6023:2018)
- [ ] Sem código GPL/AGPL
- [ ] Sem dados pessoais de alunos
- [ ] Skill testada em ambiente isolado
